# Проверка формул без внешних CDN

Эта страница предназначена для проверки математических формул при недоступности внешних CDN. Библиотека KaTeX, её стили и математические шрифты загружаются с того же сайта. Для основного текста используются системные шрифты.

## Тестовая формула

Для оценки точности предсказаний используется среднеквадратичная ошибка. Её вычисление показано в [формуле (1)](#mse).

<a id="mse"></a>

$$
\operatorname{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2 \tag{1}
$$

Здесь $n$ — количество наблюдений, $y_i$ — измеренное значение, а $\hat{y}_i$ — предсказанное значение.

## Как проверить

1. Заблокировать внешние сетевые запросы, сохранив доступ к самому сайту.
2. Отключить кэш браузера и перезагрузить страницу.
3. Убедиться, что видны дробь, знак суммы, индексы и номер формулы.
4. Проверить, что файлы KaTeX и его шрифты загружаются с адреса сайта.

Контрольная строка: **FORMULA_LOCAL_OK**.
