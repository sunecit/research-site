# Сжатие сайта

## Методика

Версия эксперимента: **v1.0**.

Используем фиксированный TAR-архив файлов статического сайта.
Выполняем сжатие алгоритмом gzip с уровнем **1**.

После одного предварительного запуска проводим
11 измерений и вычисляем медиану времени.
Чтение исходного файла и запись результата не входят в измеряемое время.

## Результаты

| Показатель | Значение |
|---|---:|
| Исходный размер, байт | 4167680 |
| Размер после сжатия, байт | 1746009 |
| Уменьшение размера | 58.11% |
| Медиана времени сжатия, мс | 24.529 |
| Количество измерений | 11 |

Проверка распаковки подтвердила полное совпадение
восстановленных данных с исходными.

## Воспроизводимость

Исходные данные: архив `experiments/input/site-snapshot.tar`.

SHA-256 исходного архива:

`2feb81f4a6f7a051cf023d4557262de8550dd9c32da54a6bfd07f71d60238044`

Скрипт вычислений: `scripts/compress_site.py`.

Результаты измерений: `experiments/results/v1.0.json`.

Версия Python: 3.14.10. Версия zlib: 1.2.12.

Система, в которой выполнены измерения: macOS-26.2-arm64-arm-64bit-Mach-O.
